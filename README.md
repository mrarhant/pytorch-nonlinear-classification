🌍 Sismik Aktivite İkili Sınıflandırma (PyTorch ile Non-Lineer Sınıflandırma)

Bu repo, yeraltı sismik dalga enerjisi ve titreşim varyasyonları üzerinden sismik olayların tespitini (seismic_event_detected) amaçlayan derin öğrenme tabanlı bir ikili sınıflandırma (binary classification) çalışmasını içermektedir.

Projenin temel odağı; doğrusal (linear) modellerin dairesel/halkasal veri dağılımlarındaki yetersizliğini analiz etmek ve doğrusal olmayan (non-linear - ReLU) aktivasyon fonksiyonları ile karar sınırlarını (decision boundaries) başarıyla eğitmektir.

📌 Proje Özeti

Amaç: 2 boyutlu öznitelik uzayında dairesel yapıdaki sismik olayları tespit etmek.

Problem Türü: İkili Sınıflandırma (Binary Classification - 0 veya 1).

Kullanılan Kütüphaneler: PyTorch, NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn.
